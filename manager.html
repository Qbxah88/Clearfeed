Connection

With a hub, settings and the activity log live on your own Cloudflare worker. Without one, settings are read and saved in settings.json on GitHub (no log). Keys are kept only in this browser.

How to make a token (2 minutes)

1. Open github.com/settings/personal-access-tokens/new.
2. Name it ClearFeed Manager, expiry 1 year.
3. Repository access: Only select repositories → Clearfeed.
4. Permissions → Repository permissions → Contents: Read and write.
5. Generate, copy the token, paste it above, click Remember token.

Earn it (TV)

A First/Then board on the TV's YouTube home screen. A Learn row comes first; finishing a learning video properly fills a star, enough stars earn a song, and a Songs row appears. Song channels stay hidden until a song is earned. Paste video links, playlist links, channel links or @handles.

Spending pause

Computers with ClearFeed installed. Before a Pay, Place order or Book now button works, a pause screen asks what it's for, whether you already have it, whether it can wait, and how you're paying. Waiting saves the page to a list with a reminder; going ahead needs a reason and a short countdown. An evening summary says what you kept.
