ClearFeed Manager

One settings file for every device. Edits go to settings.json in Qbxah88/Clearfeed; the TV and every computer running ClearFeed Web pick them up within about 10 minutes, or on next launch.

Connection

Reading needs nothing. Saving needs a GitHub token so this page can commit on your behalf. It's kept only in this browser.

How to make a token (2 minutes)

1. Open github.com/settings/personal-access-tokens/new.
2. Name it ClearFeed Manager, expiry 1 year.
3. Repository access: Only select repositories → Clearfeed.
4. Permissions → Repository permissions → Contents: Read and write.
5. Generate, copy the token, paste it above, click Remember token.
